# Jeux de management

Un plateau commun, treize jeux de management sur téléphone (QR code, sans compte). Public : Master 1, Master 2, managers.

- Jouer : activer GitHub Pages sur ce dépôt, puis ouvrir `https://belmdeveloppement.github.io/jeux-management/`
- `docs/` : règles pour les joueurs et guides animateur corrigés (un PDF par jeu)
- `plateau/` : plateau commun (aperçu, version impression 506 x 506 mm, QR du site)
- CAP MANAGER (jeu 04) reste dans son propre dépôt, relié depuis le site.
