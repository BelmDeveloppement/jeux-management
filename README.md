# Jeux management (jeu 4)

Jeu 4 « Jeux management » : un plateau commun, jeux 4.2 à 4.14 (Le bon style est le 4.1) sur téléphone (QR code, sans compte). Public : Master 1, Master 2, managers.

- Jouer : activer GitHub Pages sur ce dépôt, puis ouvrir `https://belmdeveloppement.github.io/jeux-management/`
- `docs/` : règles pour les joueurs et guides animateur corrigés (un PDF par jeu)
- `plateau/` : plateau commun (aperçu, version impression 506 x 506 mm, sans QR : le QR est dans chaque guide animateur)
- Le bon style (jeu 4.1) reste dans son propre dépôt, relié depuis le site.
